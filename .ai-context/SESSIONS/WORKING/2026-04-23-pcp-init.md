## Goal
Implement all 43 tasks defined in the PCP change to establish cross-session context persistence for the oh-mermory project.

## Key Decisions
- D001: File system as persistence medium — zero dependencies, human-readable, git-friendly
- D002: Three-layer memory model with on-demand loading — startup < 500 tokens
- D003: Checkpoint + Git dual safety net — complementary recovery mechanisms
- D004: Session tiered storage (TEMP/WORKING/ARCHIVED) — controlled file growth
- D005: AGENTS.md as integration entry point — automatic context loading
- D006: MCP extension interface reserved — future-proof without initial complexity
